Calm loaders

What is wrong with loading today, and how it would look on the Lead Agent.

What can be better

Page switch
Same grey blocks on every page. The page jumps when it arrives.
Blocks shaped like the page that is coming (tool, module, Today), then a soft fade in.
Too many spinners
About 10 different spinners and 6 skeleton styles (md-spin, tsp-spin, td-btn-spinner, an-skeleton, ov-skel…), some written inline.
One spinner, one skeleton, one progress panel. Everything uses them.
Flashing
Spinners show even for very short waits, so the screen flickers.
Show nothing for the first 300 ms.
Long AI waits
Module analysis, drafts, review reading and keyword scans show a tiny "Analysing…" in the button for up to 90 s.
Over 5 s: steps, time left, and a "While you wait" card.
Agent runs
Steps list is good, but there is no sense of how far along it is and nothing to read for 1–3 min.
Add a progress bar, time left and the card. Keep "you can leave this page".
Words
"Loading…", "Loading campaigns…", "Requesting…", "Scanning...".
Say what is happening: "Reading Bloom Salon's website".
Slow or failed
Some waits never time out; others fail with a bare error.
After 2× the usual time: "Taking longer than usual", plus Try again.
Page info
No place to learn what a tool is for, apart from the first-visit intro.
An "About this page" link in the grey top line, with the same cards.

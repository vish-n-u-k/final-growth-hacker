## DEVELOPER INTEGRATION GUIDE

### Data Structure Format

Each actionable item follows this JSON structure:
```json
{
  "section": [NUMBER],
  "sectionTitle": "[SECTION_TITLE]",
  "itemId": "[SECTION].[ITEM_NUM]",
  "priority": "[CRITICAL|HIGH|MEDIUM|LOW]",
  "title": "[ITEM_TITLE]",
  "description": "[DETAILED_DESCRIPTION]",
  "timeline": "[TIMELINE_STRING]",
  "effortHours": [NUMBER],
  "expectedImpact": "[IMPACT_DESCRIPTION]",
  "successMetric": "[HOW_TO_MEASURE]",
  "owner": "[PERSON_OR_TEAM]",
  "dependencies": ["[ITEM_ID]", "[ITEM_ID]"],
  "completed": false,
  "completedDate": null,
  "notes": ""
}
```

### CSV Export Format
```
SectionNum,SectionTitle,ItemID,Priority,Title,Timeline,EffortHours,Owner,Completed,CompletedDate,Notes
```

### Database Schema
```sql
CREATE TABLE audits (
  id UUID PRIMARY KEY,
  businessName VARCHAR(255),
  auditType VARCHAR(100),
  reportDate DATE,
  overallScore INT,
  totalItems INT
);

CREATE TABLE sections (
  id UUID PRIMARY KEY,
  auditId UUID REFERENCES audits(id),
  sectionNumber INT,
  sectionTitle VARCHAR(255),
  score INT,
  status VARCHAR(50),
  priority VARCHAR(50)
);

CREATE TABLE actionItems (
  id UUID PRIMARY KEY,
  sectionId UUID REFERENCES sections(id),
  itemNumber INT,
  priority VARCHAR(50),
  title VARCHAR(255),
  description TEXT,
  timeline VARCHAR(100),
  effortHours INT,
  owner VARCHAR(255),
  completed BOOLEAN DEFAULT FALSE,
  completedDate DATE,
  notes TEXT
);
```

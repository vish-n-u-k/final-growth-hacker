# Gopal Patel — Portfolio

A single-file, dependency-free animated portfolio site (`index.html`).

- All fonts (Syne, Instrument Sans, JetBrains Mono) are embedded as data URIs — no CDN calls, works offline.
- Light and dark themes (follows system preference, with a manual toggle in the nav).
- Animations: orchestrated hero reveal, typed JSON intro, ambient component-graph canvas, scroll-drawn timeline, skills marquee. Respects `prefers-reduced-motion`.

## Deploy

Any static host works — drop `index.html` on Vercel, Netlify, or GitHub Pages as-is.
